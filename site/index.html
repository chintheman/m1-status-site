How it works

This page is the public face of a monitoring system for a MacBook Air (M1, 8GB, fanless) that runs 24/7 at a remote location with no physical access. A collector on the machine pushes a masked health snapshot every 15 minutes; this page renders it. The private side (full detail + actions) never touches the public internet.
